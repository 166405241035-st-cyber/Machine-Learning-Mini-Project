02 / THE MODEL

อ่านสมการให้เข้าใจ

PM2.5 = {{ '%.4f'|format(report.intercept) }}
− {{ '%.4f'|format(-report.coefficients.temperature_c) }}T − {{ '%.4f'|format(-report.coefficients.humidity_percent) }}H − {{ '%.4f'|format(-report.coefficients.wind_speed_ms) }}W

T: อุณหภูมิ (°C) · H: ความชื้น (%) · W: ลมที่ 10 เมตร (m/s)
ทุกตัวเป็นค่าเฉลี่ยรายวัน ผลลัพธ์มีหน่วย µg/m³

  • อุณหภูมิเพิ่ม 1°C ค่าฝุ่นที่โมเดลประมาณลดลง {{ '%.3f'|format(-report.coefficients.temperature_c) }} µg/m³ เมื่อคงความชื้นและลมไว้
  • ความชื้นเพิ่ม 1 จุดเปอร์เซ็นต์ เช่น 70% เป็น 71% ค่าฝุ่นที่โมเดลประมาณลดลง {{ '%.3f'|format(-report.coefficients.humidity_percent) }} µg/m³ เมื่อคงตัวแปรอื่นไว้
  • ลมเพิ่ม 1 m/s ค่าฝุ่นที่โมเดลประมาณลดลง {{ '%.3f'|format(-report.coefficients.wind_speed_ms) }} µg/m³ เมื่อคงตัวแปรอื่นไว้

จุดตัดแกน {{ '%.2f'|format(report.intercept) }} คือค่าคำนวณเมื่อทั้งสามตัวแปรเป็นศูนย์ ซึ่งอยู่นอกช่วงชุดฝึก จึงไม่ใช่ค่าฝุ่นพื้นฐานจริงของพื้นที่

ตัวอย่าง T=30, H=70, W=2 → ประมาณ 32.30 µg/m³
สมการแสดงตัวเลขปัดเศษ โค้ดคำนวณด้วยสัมประสิทธิ์เต็ม

เปรียบเทียบผลของตัวแปรบนสเกลเดียวกัน

{{ figure('03_coefficient_effects', 'ผลต่อค่าฝุ่นที่โมเดลประมาณเมื่อตัวแปรแต่ละตัวเพิ่มหนึ่งส่วนเบี่ยงเบนมาตรฐานของชุดฝึก') }}

ขนาดสัมประสิทธิ์ดิบเปรียบเทียบข้ามตัวแปรโดยตรงไม่ได้ เพราะแต่ละตัวใช้คนละหน่วย กราฟนี้คูณสัมประสิทธิ์ด้วยส่วนเบี่ยงเบนมาตรฐานของตัวแปรในชุดฝึก เพื่อเทียบผลเมื่อเพิ่มหนึ่ง SD โดยคงตัวแปรอื่นไว้ เป็นคำอธิบายพฤติกรรมโมเดล ไม่ใช่การพิสูจน์อิทธิพลเชิงสาเหตุ และยังไม่มีช่วงความเชื่อมั่น

03 / HELD-OUT EVALUATION

ประมาณได้ดีเพียงใด และพลาดแบบไหน

ลด MAE เทียบ baseline{{ '%.1f'|format(stats.mae_improvement_percent) }}%

ผลจริงเทียบผลประมาณ และ residual

{{ figure('04_prediction_residuals', 'กราฟผลจริงเทียบผลประมาณและกราฟ residual บนชุดทดสอบ') }}

จุดใกล้เส้นทแยงหมายถึงค่าประมาณใกล้ค่าจริง ส่วน residual = ค่าจริง − ค่าประมาณ ถ้าเป็นบวกคือโมเดลประมาณต่ำไป ถ้าเป็นลบคือประมาณสูงไป

โมเดลประมาณสูงกว่าค่าจริง {{ stats.test_overestimated_days }} จาก {{ report.test.rows }} วัน และมี residual เฉลี่ย {{ '%.2f'|format(stats.mean_test_residual) }} µg/m³ จึงมีแนวโน้มประมาณสูงเกินจริงในชุดทดสอบนี้ แม้ MAE จะดีกว่า baseline

เทียบกับวิธีพื้นฐานบนวันทดสอบเดียวกัน

{{ figure('05_test_performance', 'กราฟ MAE RMSE เปรียบเทียบ baseline และค่าฝุ่นจริงกับค่าประมาณตามเวลา') }}

Baseline ใช้ค่าเฉลี่ยฝุ่นจากชุดฝึกทำนายทุกวัน มี MAE {{ '%.2f'|format(report.baseline.mae) }} µg/m³ เทียบกับโมเดล {{ '%.2f'|format(report.metrics.mae) }} µg/m³ ผลนี้ใช้กับการแบ่งข้อมูลครั้งนี้เท่านั้น

MAE คือขนาดความผิดพลาดเฉลี่ย ไม่ใช่ช่วงรับประกันรายครั้ง RMSE เน้นความผิดพลาดขนาดใหญ่ ส่วน R²={{ '%.3f'|format(report.metrics.r2) }} อธิบายความแปรปรวนของชุดทดสอบได้ประมาณ {{ '%.1f'|format(report.metrics.r2 * 100) }}% ไม่ได้แปลว่าทำนายถูกเท่านั้นเปอร์เซ็นต์
